## Website Description

**Purpose:** Wattwise is an educational website about SDG 7 (Affordable and Clean Energy). It helps visitors understand the goals of SDG 7, renewable energy sources, the impact of wasted electricity, and how to save electricity and make a home more eco-friendly.

**Benefits:**

- Provides a basic understanding of SDG 7 and renewable energy.
- Shows the connection between daily habits, electricity bills, and the environment.
- Offers practical tips that can be applied at home right away.

**Target users:** Students, university students, and the general public who want to learn how to save energy at home.

## Website Pages

Home, About SDGs, Renewable Energy, Energy Impact, Green Home, Saving Tips, About Us

## Technologies

- **HTML5:** page structure with semantic elements (header, nav, main, section, footer, details/summary).
- **CSS3:** styling, CSS variables (:root), transitions, and shadows.
- **Flexbox and Grid:** layout for the navbar, cards, steps, and footer.
- **CSS Media Queries:** responsive display for tablets and phones.
- **GitHub Pages:** website hosting.
